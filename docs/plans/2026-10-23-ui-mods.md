# UI Mods Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the needs-you pulse, the usage color ramp, a compact right status, and a distinct needs-you sound. (Desktop notice removed 2026-11-13.)

**Architecture:** Pure functions go in `wezterm/logic.lua` (luajit tests). The hook `hooks/track-state.sh` gains a `since` field and the needs-you sound. `wezterm/tracker.lua` turns logic output into FormatItems. Segments are `{ text = string, tone = string|nil }` where tone is one of `ok`, `warn`, `hot`, `needs-you`, `working`, `idle`.

**Tech Stack:** POSIX sh, jq, WezTerm Lua (build 20240203), luajit for tests.

**Spec:** `docs/specs/2026-10-23-ui-mods-design.md`

## Global Constraints

- Hooks always exit 0, never print to stdout, never block.
- New runtime Lua code is wrapped in `pcall`. A Lua error in `format-tab-title` breaks the whole tab bar.
- Tests never play real sounds: `SESSION_TRACKER_SOUND=""`, `SESSION_TRACKER_SOUND_NEEDS=""` exported at the top of `tests/track_state_test.sh`.
- Pulse: first 8 s after `since`, alternating seconds, then steady. Usage cutoffs: `ok` under 70, `warn` 70 to 89, `hot` 90 and up. Compact below 100 columns. Needs-you sound `/System/Library/Sounds/Glass.aiff`.
- Counts go last in the right status (WezTerm clips from the left).
- No em dashes in code, comments or docs. Match the existing comment density.
- Do not commit. The user commits when they say so.

## Review Focus

- State file from before the upgrade has no `since`: no crash, no pulse.
- Old state file empty or corrupt JSON: hook still writes a fresh file, `since` = now.
- Usage cache lines blank or non-numeric: `usage n/a` or plain segment, no Lua error.
- `since` in the future (clock change): `pulse_on` is false.
- Window column count unavailable: treat as wide.

- [ ] **Step 3: Implement** the signatures above in `wezterm/logic.lua`.

  - `count_segments`: wide returns one untoned segment of `M.summary(counts)` (or `{}` when empty). Compact returns one `"● N"` segment per non-zero state in order needs-you, working, idle, tone = the state, separated by untoned `"  "` segments.
  - `right_segments`: usage, then `{ text = " │ " }` only if both lists are non-empty, then counts.

### Task 3: WezTerm glue

**Files:**
- Modify: `wezterm/tracker.lua`

**Interfaces:**
- Consumes: `logic.pulse_on`, `logic.usage_segments`, `logic.count_segments`, `logic.right_segments`, `logic.COMPACT_COLS`.
- Produces: `tracker.tab_view(tab)` also returns `since` (number|nil) of the pane whose state is the worst, only when that state is `needs-you`. `tracker.pulse_on(since) -> boolean` (calls `logic.pulse_on(since, os.time())` inside `pcall`, false on error).

- [ ] **Step 1:** In `tab_view`, track the `since` of needs-you records and return it in the view table.
- [ ] **Step 2:** Add `tracker.pulse_on`.
- [ ] **Step 3:** In `update-right-status`, read `window:active_tab():get_size().cols` inside `pcall` (nil means wide), compute `compact = cols ~= nil and cols < logic.COMPACT_COLS`, build segments with the Task 1 functions, and emit one `Foreground` plus `Text` FormatItem pair per segment. Tone colors: `ok` = idle green, `warn` = working yellow, `hot` and `needs-you` = rose, `working` and `idle` = their `COLORS`, nil tone = `BAR_FG`. The whole body stays inside the existing `pcall` fallback to `""`.
- [ ] **Step 4: Verify in a scratch WezTerm** (do not touch the live config): run a scratch instance with a config that requires this `tracker.lua`, a state dir via `SESSION_TRACKER_STATE_DIR`, and a hand-written state file `{state:"needs-you", since:<now>}`. Confirm (a) `format-tab-title` is re-invoked each second without any input, (b) `get_size().cols` returns a number, (c) usage segments change color when the usage cache is edited to 75 then 95. If (a) fails, stop and report; the pulse design needs revisiting.
- [ ] **Step 5:** Show the user the exact change needed in `~/.wezterm.lua` (the needs-you tab background becomes `tracker.pulse_on(view.since) and <brighter rose> or <current rose>`). Do not edit that file without their yes.
- [ ] **Step 6: Run** `sh tests/run.sh`. Expected: exit 0.
